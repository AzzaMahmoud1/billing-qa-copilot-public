# Examples

Worked runs of the method on a real-shaped story, so you can see the expected output.

- [`example-create-invoice.md`](example-create-invoice.md) — *"As a product, create a dynamic-priced
  invoice and push it to Sadad in real time (+ ZATCA if configured)."* Shows three testable units
  (TU-01/04/05) filled into the output template, each with the API slot, the exact `{{TBL_*}}` SQL
  verification, the UI surface, and the edge cases.

All identifiers in examples are **synthetic/illustrative** — safe for the public build. To produce your
own, follow `method/story-analysis-method.md` or just hand the story to the agent (`CLAUDE.md`).
