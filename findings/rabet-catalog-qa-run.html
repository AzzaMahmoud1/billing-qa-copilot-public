Cases executed
Eligibility mechanism found. Rabet eligibility is the EnableRabetInquiry setting in {{TBL_SETTING}} (SET_VALUE=1, keyed by product) — not an opaque 3scale-only gate as first believed. Proof: product 992 (flag=1, zero packages) returns 1193 "No packages found" (eligible & empty), while 199 (no flag) returns 1005 "The Application Not Exists" (not eligible). So 1005=ineligible; 1191/1193=eligible-but-empty. A product can be made eligible by setting the flag (+ cache refresh).
